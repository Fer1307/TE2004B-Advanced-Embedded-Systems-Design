# Módulo 2 · Procesamiento digital de señales

**Profesor:** Dr. David Antonio Torres

Este módulo cubre señales y sistemas en tiempo discreto: muestreo, suma de convolución, ecuaciones en diferencias, transformada Z, series y transformada discreta de Fourier (DFT/FFT) y filtros digitales FIR e IIR. Los conceptos se aplican a imágenes en MATLAB como preparación para la etapa de visión del reto.

## Contenido

| Carpeta | Descripción |
|---|---|
| [`activity03-filter2d/`](activity03-filter2d/) | **Actividad 3:** filtros 2D sobre una imagen en escala de grises: desenfoque por movimiento (`fspecial("motion")`), desenfoque tipo lente (`fspecial("disk")`) y detección de bordes. Incluye el Live Script (`act3_filter2d.mlx`) y su exportación en PDF. |
| [`examples/`](examples/) | Convolución 2D con un kernel Sobel (`conv2_example01.m`) y prueba de cámara web (`camera.m`). |

## Requisitos

MATLAB con Image Processing Toolbox e Image Acquisition Toolbox (soporte para webcam).

# Módulo 1 · Análisis y diseño de algoritmos

**Profesor:** Dr. César Torres Huitzil

Este módulo analiza la eficiencia de los algoritmos (complejidad temporal y espacial) y los aplica a problemas de ordenamiento y de procesamiento de imágenes, como base para los algoritmos de visión computacional del reto.

## Contenido

| Carpeta | Descripción |
|---|---|
| [`sorting-algorithms/`](sorting-algorithms/) | Implementaciones en Python de Insertion Sort y Bubble Sort con medición de tiempo, y pruebas con arreglos de distintos tamaños. |
| [`computer-vision/`](computer-vision/) | Correlación bidimensional (`2d_correlation_exercise.py`), visualización de una imagen con OpenCV (`computer_vision1.py`), filtro de mediana basado en Insertion Sort (`filtro_mediana.py`) y manejo de bordes con padding (`filtro_padding.py`). |
| [`reports/`](reports/) | **Actividad 01.1.3:** análisis comparativo de Insertion Sort, Bubble Sort y Merge Sort contando comparaciones con 10, 100, 1,000 y 10,000 elementos, y el notebook de Colab. |
